# KnexCoins Landing

Landing page for knexcoins.com — the public-facing entry point for KnexCoin.

**Live**: [knexcoins.com](https://knexcoins.com)

---

## Overview

Static landing page with project overview, key features, and links to the ecosystem (wallet, exchange, whitepaper, faucet).

## Files

```
knexcoins-landing/
├── CNAME          # GitHub Pages custom domain (knexcoins.com)
└── index.html     # Landing page
```

## Deployment

Deployed via GitHub Pages from the `knexcoin/knexcoins.com` repository. The `CNAME` file configures the custom domain.
